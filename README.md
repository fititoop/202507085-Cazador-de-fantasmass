# FASE 1:
En esta fase diseñé y estructuró el videojuego de acción y aventura "Cazador de Fantasmas", una propuesta interactiva donde los jugadores asumen el rol de Alex Hunter con el objetivo de explorar una antigua mansión embrujada y cerrar un portal paranormal generado por un experimento fallido. Para construir el proyecto, desarrollé una progresión de 5 niveles temáticos (desde la Entrada hasta la Sala del Portal), un catálogo de 4 tipos de enemigos con mecánicas variadas (fantasmas comunes, veloces, invisibles y explosivos) liderados por el Rey Fantasma, un sistema de habilidades para el héroe que incluye linterna reveladora y escudos, y un esquema de controles WASD con puntuación acumulativa por cada captura realizada.
# FASE 2
Este diagrama de flujo define la estructura lineal de "Cazador de Fantasmas", donde el jugador controla a Alex Hunter usando un esquema WASD, Espacio, E y Shift. La partida progresa de forma condicionada a través de 5 niveles temáticos con dificultad y recompensas escalonadas: la Entrada (fantasmas comunes, +10 pts); la Biblioteca (fantasmas veloces, +20 pts y la Llave Mágica); el Laboratorio (trampas y fantasmas invisibles que requieren linterna, +30 pts); y el Sótano (espacio reducido y fantasmas explosivos, +40 pts). Todo culmina en la Sala del Portal, donde vencer al Rey Fantasma (+500 pts) sella la meta final de cerrar el portal y liberar las almas.
# FASE 3
Este script en Python implementa la lógica de "Cazador de Fantasmas" usando programación orientada a objetos. Define la clase padre Fantasma y usa herencia y polimorfismo para crear las cinco subclases de enemigos. Cada una posee valores únicos de daño, recompensa y mecánicas de ataque personalizadas. Por otro lado, la clase AlexHunter gestiona la salud, la puntuación y el inventario del protagonista. Finalmente, mediante funciones de consola y condicionales, el programa simula de forma interactiva la progresión lineal de los 5 niveles temáticos. El sistema valida las acciones del teclado, calcula el daño recibido y define la victoria tras derrotar al jefe final.
